# Repo Dungeon

Paste any public GitHub repo → play it as a dungeon in the browser.

Folders become rooms, the biggest file is the boss, every `TODO` is a goblin, open issues haunt the halls as ghosts, and `node_modules` is a bottomless pit.

**Status:** planning. See [SPEC.md](SPEC.md) for the full spec and milestones.
